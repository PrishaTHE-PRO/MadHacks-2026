Try it in a few minutes

Second Look runs from source while it's in development.

  1. Get the code Clone the repo and install. 
    git clone https://github.com/PrishaTHE-PRO/MadHacks-2026.git
cd MadHacks-2026 && npm install
  2. Start the server and build Add an Anthropic key to server/.env for the full checks. 
    npm run server
npm run ext
  3. Load it in Chrome Open chrome://extensions, turn on Developer mode, click Load unpacked and pick extension/dist.

Full setup in the README
